## 📖 About This Repository

This repository documents the **Front-End Development learning journey of Hamza Al-Tabbab (حمزة التباب)** under the mentorship of **Eng. Hasan Hajjar (المهندس حسن حجار)**, founder and lead of **AQL RAQAMI (عقل رقمي)**.

The program combines structured lessons, hands-on exercises, code reviews, and progressively more advanced projects. Its goal is to build the practical skills required to develop **responsive, accessible, maintainable, and interactive web applications**.

> **بالعربية:** يوثّق هذا المستودع المسار التدريبي العملي للطالب **حمزة التباب** في تطوير الواجهات الأمامية، بإشراف **المهندس حسن حجار**، ضمن التدريب المقدم من شركة **عقل رقمي**. يبدأ المسار من أساسيات HTML وCSS وJavaScript وصولًا إلى React وبناء تطبيقات ويب متكاملة، مع تطبيقات وتمارين ومراجعات دورية للكود.

## 🎯 Training Objectives

- Understand web fundamentals, semantic HTML, and accessible page structure.
- Create polished, responsive interfaces using modern CSS.
- Master JavaScript fundamentals, DOM manipulation, and asynchronous programming.
- Build reusable components and interactive applications with React.
- Work confidently with Git, GitHub, debugging tools, and development workflows.
- Apply clean-code principles, code review, and practical problem-solving.
- Develop a substantial final project showcasing the skills learned.

## 🧭 Learning Roadmap

| Phase | Focus | Practical outcomes |
| :--- | :--- | :--- |
| **01 — Web Foundations** | Internet basics, VS Code, HTML5, semantic structure, forms | Structured web pages |
| **02 — Modern CSS** | Selectors, box model, Flexbox, Grid, responsive design, animations | Responsive layouts |
| **03 — JavaScript Fundamentals** | Variables, types, functions, conditions, loops, arrays, objects | Interactive exercises |
| **04 — Browser & Advanced JS** | DOM, events, validation, Fetch API, async/await, modules | API-powered mini apps |
| **05 — React** | Components, JSX, props, state, hooks, routing, forms | Component-based apps |
| **06 — Professional Workflow** | Git/GitHub, debugging, accessibility, performance, deployment | Production-ready practices |
| **07 — Capstone Project** | Planning, UI design, implementation, testing, deployment | Complete portfolio project |

> The roadmap is adaptable to the learner's progress. Lesson count and final project scope will be confirmed during training.

## 🛠️ Technologies & Tools

**Core:** HTML5 · CSS3 · JavaScript (ES6+) · React  
**Styling & UI:** Responsive Design · Flexbox · CSS Grid  
**Workflow:** Git · GitHub · Visual Studio Code · Browser DevTools  
**Additional tools:** Introduced as needed by the training projects.

## 🔄 Learning & Development Workflow

1. **Learn:** Study each concept and review examples.
2. **Practice:** Complete exercises independently.
3. **Build:** Implement increasingly complex components and projects.
4. **Review:** Receive technical feedback and improve code quality.
5. **Document:** Commit meaningful progress and maintain project documentation.
6. **Showcase:** Present and deploy the final project when ready.

## 🏆 Training Certificate

Upon successfully completing the agreed curriculum, practical assignments, and final project assessment, the trainee may receive a **Certificate of Training Completion and Practical Skills** issued by **AQL RAQAMI (عقل رقمي)**.

The certificate documents the completed training and assessed skills; it does **not** represent employment history or professional work experience unless separately verified.

<h2>📖 نبذة عن المستودع</h2>

<p>يوثّق هذا المستودع الرحلة التعليمية والتطبيقية للطالب <strong>حمزة التباب (Hamza Al-Tabbab)</strong> في مسار <strong>تطوير واجهات ومواقع الويب الأمامية</strong>، بإشراف وتوجيه <strong>المهندس حسن حجار (Eng. Hasan Hajjar)</strong>، مؤسس شركة <strong>عقل رقمي (AQL RAQAMI)</strong> ومديرها.</p>

<p>صُمّم البرنامج على هيئة <strong>مسار تدريبي ممتد متعدد الجلسات</strong> يجمع بين الشرح المنهجي، والأمثلة العملية، والتمارين، والمشاريع المتدرجة، ومراجعة الشيفرة البرمجية وتطويرها. ويبدأ من أساسيات <strong>HTML وCSS وJavaScript</strong>، وصولًا إلى <strong>React</strong> وبناء واجهات وتطبيقات ويب تفاعلية قابلة للتطوير والصيانة.</p>

<p>لا يقتصر الهدف على معرفة طريقة كتابة الشيفرة، بل يشمل فهم آلية عمل الويب، وبناء واجهات متجاوبة وسهلة الاستخدام، وتطبيق الممارسات البرمجية الاحترافية، والاستعداد لتنفيذ مشاريع حقيقية وتوثيقها عبر GitHub.</p>

<h2>🎯 الأهداف التدريبية</h2>

<ul>
<li>فهم أساسيات الإنترنت والويب، وكيفية عمل المتصفح وعناصر صفحات الويب.</li>
<li>استخدام <strong>HTML5</strong> لبناء صفحات منظّمة ذات بنية دلالية واضحة ونماذج إدخال سليمة.</li>
<li>إتقان <strong>CSS3</strong> لإنشاء تصاميم جذابة ومتجاوبة مع الهاتف والأجهزة اللوحية والحاسوب.</li>
<li>توظيف <strong>JavaScript</strong> لتنفيذ المنطق البرمجي، والتفاعلات، والتحقق من المدخلات، والتعامل مع البيانات.</li>
<li>فهم <strong>DOM</strong> والأحداث، والتعامل مع واجهات البرمجة <strong>APIs</strong> والعمليات غير المتزامنة.</li>
<li>تطوير تطبيقات تعتمد على المكونات القابلة لإعادة الاستخدام باستخدام <strong>React</strong>.</li>
<li>استخدام أدوات المطور، و<strong>Git وGitHub</strong> لإدارة الإصدارات وتوثيق العمل.</li>
<li>التدرّب على تنظيم الملفات، وإعادة استخدام الشيفرة، وتصحيح الأخطاء، وتحسين الأداء وإمكانية الوصول.</li>
<li>تطبيق مراجعات دورية للشيفرة وتقبّل الملاحظات التقنية وإدخال التحسينات.</li>
<li>إنجاز <strong>مشروع نهائي متكامل</strong> يبرز المهارات المكتسبة خلال التدريب.</li>
</ul>
